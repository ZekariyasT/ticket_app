# Flutter Ticket App

## Overview
The **Flutter Ticket App** is a mobile application designed for booking airplane tickets. The app allows users to browse available flights, view different hotels and their prices, and book tickets seamlessly. Built with Flutter, the app ensures a smooth and intuitive user experience with a modern UI.

## Features
- **Flight Booking**: Search and book airplane tickets easily.
- **Hotel Listings**: View different hotels along with their prices.
- **Modern UI**: Smooth and intuitive interface designed with Flutter.

## Technologies Used
- **Flutter** (Dart) - Frontend framework
- **REST API** - Fetch flight and hotel data
- **Provider ** - State management

## Installation
1. **Clone the repository**
   ```sh
   git clone https://github.com/your-username/flutter-ticket-app.git
   cd flutter-ticket-app
   ```
2. **Install dependencies**
   ```sh
   flutter pub get
   ```
3. **Run the app**
   ```sh
   flutter run
   ```
